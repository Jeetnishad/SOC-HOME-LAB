# Wazuh Installation

## Objective

Install and configure Wazuh SIEM on Kali Linux for centralized log collection, threat detection, and security monitoring.

---

## Steps Performed

### 1. Updated the Operating System

- Updated package repositories.
- Installed the latest security updates.

### 2. Installed Wazuh

- Installed Wazuh Manager.
- Installed Wazuh Indexer.
- Installed Wazuh Dashboard.

### 3. Started Services

Verified that the following services were running:

- Wazuh Manager
- Wazuh Indexer
- Wazuh Dashboard

### 4. Dashboard Verification

Successfully accessed the Wazuh Dashboard through the web browser.

---

## Result

Wazuh SIEM was successfully deployed and became ready to receive logs from monitored endpoints.
