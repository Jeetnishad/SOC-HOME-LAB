# Sysmon Configuration

## Objective

Configure Sysmon to collect detailed endpoint telemetry for security monitoring.

---

## Steps Performed

### 1. Downloaded Sysmon

Downloaded Sysmon from Microsoft Sysinternals.

### 2. Installed Sysmon

Installed Sysmon with administrator privileges.

### 3. Applied Configuration

Configured Sysmon using an XML configuration file.

### 4. Verification

Verified that Sysmon was successfully generating Windows security events.

---

## Result

Sysmon enhanced endpoint visibility by capturing process creation, network connections, and other security-related events for analysis through Wazuh.
