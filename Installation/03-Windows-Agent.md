# Windows Agent Installation

## Objective

Install the Wazuh Agent on Windows 10 and connect it to the Wazuh Manager.

---

## Steps Performed

### 1. Downloaded the Wazuh Agent

Installed the latest compatible version of the Wazuh Agent.

### 2. Configured the Agent

Configured the Wazuh Manager IP address inside the agent configuration.

### 3. Started the Service

Verified that the Wazuh Agent service was running successfully.

### 4. Registration

Confirmed that the Windows endpoint appeared as an active agent in the Wazuh Dashboard.

---

## Result

The Windows endpoint successfully communicated with the Wazuh Manager and started forwarding security events.
