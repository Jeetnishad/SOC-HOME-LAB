# MITRE ATT&CK Mapping – T1059.001: PowerShell

## Overview

This document maps the PowerShell activity performed during LAB-02 to the MITRE ATT&CK framework.

The objective of this lab was to validate Wazuh's capability to detect PowerShell execution using Windows event logs and Sysmon telemetry, enabling a SOC analyst to investigate command execution on a Windows endpoint.

# Technique Description

PowerShell is a legitimate Windows administrative tool that attackers frequently abuse to execute malicious commands, download payloads, perform reconnaissance, establish persistence, and evade detection.

Monitoring PowerShell activity enables security teams to identify suspicious command execution and investigate potential attacks before they escalate.

---

# Attack Simulation

PowerShell commands will be executed on the monitored Windows endpoint.

The execution will generate Windows events and Sysmon Process Creation events that are forwarded by the Wazuh Agent to the Wazuh Manager.

The generated alerts will be investigated through the Wazuh Dashboard.

---

# Detection Workflow

1. PowerShell is executed.
2. Sysmon records Process Creation.
3. Windows logs the activity.
4. Wazuh Agent collects the events.
5. Events are forwarded to the Wazuh Manager.
6. Wazuh detection rules analyze the activity.
7. Alerts are generated for investigation.

# Detection Logic

The detection relies on monitoring PowerShell execution using Windows logging and Sysmon process creation telemetry.

When PowerShell is launched, Sysmon records the process creation event, and Wazuh analyzes the collected logs using built-in detection rules.

Alerts generated by Wazuh allow SOC analysts to investigate PowerShell activity and determine whether the execution is legitimate or potentially malicious.

# Defensive Recommendations

The following controls are recommended:

- Enable PowerShell logging.
- Enable Script Block Logging.
- Enable Module Logging.
- Monitor encoded PowerShell commands.
- Investigate suspicious PowerShell execution.
