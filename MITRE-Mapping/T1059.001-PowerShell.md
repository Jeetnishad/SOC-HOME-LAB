## Overview

PowerShell is a legitimate Windows command-line shell and scripting language widely used for system administration and automation. Because it is installed by default on modern Windows systems and provides powerful access to the operating system, attackers frequently abuse it to execute malicious commands, download payloads, perform reconnaissance, and evade traditional security controls.

Monitoring PowerShell activity is therefore a critical capability for Security Operations Centers (SOCs). This lab validates that PowerShell execution events are successfully collected by Sysmon and forwarded to Wazuh for detection and analysis.

---

## Lab Scenario

A PowerShell command is executed on the Windows 10 endpoint within the authorized SOC Home Lab environment.

The objective is to verify that:

- Sysmon records the PowerShell process creation event.
- The Wazuh Agent forwards the event to the Wazuh Manager.
- Wazuh generates an alert for analyst investigation.
- The event can be mapped to MITRE ATT&CK Technique **T1059.001 – PowerShell**.

## Investigation Workflow

1. Execute a PowerShell command on the Windows endpoint.
2. Verify that Sysmon logs the process creation event.
3. Confirm that the Wazuh Agent forwards the event.
4. Review the generated alert in the Wazuh Dashboard.
5. Analyze the process details and command line.
6. Map the activity to MITRE ATT&CK T1059.001.
7. Document the findings in the incident report.
