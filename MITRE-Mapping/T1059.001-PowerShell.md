# Overview

PowerShell is a legitimate Windows command-line shell and scripting language developed by Microsoft for system administration and automation.

Because it is installed by default on modern Windows systems and provides extensive access to operating system functionality, attackers frequently abuse PowerShell for executing commands, downloading payloads, performing reconnaissance, privilege escalation, persistence, and post-exploitation activities.

Monitoring PowerShell activity is an essential capability for Security Operations Centers (SOCs). Detecting abnormal PowerShell execution enables analysts to identify potentially malicious behavior at an early stage.

---

# Lab Objective

The objective of this lab was to validate that PowerShell execution events generated on a Windows 10 endpoint are successfully monitored using Sysmon and collected by Wazuh for centralized analysis.

The activity was performed entirely within an isolated and authorized SOC Home Lab environment.

---

# Lab Scenario

PowerShell was executed on the Windows endpoint using safe administrative commands.

Executed commands:

```powershell
Get-Process
```

```powershell
Get-ChildItem C:\Windows
```

These commands were selected because they generate legitimate PowerShell process creation events without modifying the operating system or executing malicious code.

# Security Value

Monitoring PowerShell execution enables SOC analysts to:

- Detect unauthorized script execution
- Monitor administrative activity
- Investigate suspicious process creation
- Correlate endpoint telemetry
- Improve endpoint visibility
- Support incident investigations

---

# Defensive Recommendations

To improve PowerShell monitoring within enterprise environments:

- Enable PowerShell Operational Logging
- Enable Script Block Logging
- Enable Module Logging
- Monitor unusual PowerShell command-line arguments
- Investigate encoded or obfuscated PowerShell commands
- Correlate PowerShell activity with parent processes
- Continuously review Wazuh detection rules
