# MITRE ATT&CK Mapping - T1046 (Network Service Discovery)

## Technique

| MITRE ATT&CK Technique | ID |
|------------------------|----|
| Network Service Discovery | T1046 |

---

# Overview

Adversaries commonly perform network service discovery to identify open ports and running services on a target system before attempting exploitation.

Nmap is one of the most widely used reconnaissance tools for this purpose.

---

# Lab Scenario

**Attacker**

- Kali Linux
- IP Address: 10.0.2.4

**Target**

- Windows 10
- IP Address: 10.0.2.5

Monitoring Stack:

- Sysmon
- Wazuh Agent
- Wazuh SIEM

---

# Attack Commands

## Basic Scan

```bash
sudo nmap 10.0.2.5
```

Purpose

Identify open TCP ports on the target.

---

## Advanced Scan

```bash
sudo nmap -A 10.0.2.5
```

This performs:

- OS Detection
- Version Detection
- NSE Script Scan
- Traceroute

---

# Observed Behavior

The Windows endpoint received multiple inbound connection attempts generated by Nmap.

Sysmon recorded these connections using **Event ID 3 (Network Connection)**.

The generated logs were forwarded to the Wazuh Manager for analysis.

# Security Impact

Reconnaissance is one of the earliest stages of the Cyber Kill Chain.

Identifying open services helps an attacker:

- Discover exposed services
- Identify vulnerable software
- Plan future exploitation
- Enumerate the attack surface

---

# Detection Notes

During this lab, Sysmon successfully generated Event ID 3 (Network Connection) logs.

These logs were ingested by Wazuh for investigation.

A dedicated custom Nmap detection rule was not implemented in this lab. Instead, the focus was on validating telemetry collection and analyzing reconnaissance activity through endpoint logs.
