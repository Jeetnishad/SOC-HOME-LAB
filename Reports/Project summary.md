# Project Summary

This project demonstrates the implementation of a Security Operations Center (SOC) Home Lab using Wazuh SIEM, Sysmon, Kali Linux, and Windows 10.

The environment is designed to simulate enterprise security monitoring by collecting endpoint logs, detecting suspicious activities, performing threat hunting, and documenting incident response workflows.

The project includes installation guides, architecture documentation, configuration references, detection labs, MITRE ATT&CK mapping, screenshots, and incident reports.
