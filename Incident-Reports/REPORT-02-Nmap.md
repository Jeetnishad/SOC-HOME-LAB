# Executive Summary

A network reconnaissance activity was simulated using Nmap from the Kali Linux attacker machine against the Windows 10 victim system.

The objective was to identify exposed network services and verify that the activity was logged by Sysmon and forwarded to the Wazuh SIEM for investigation.

The scan successfully generated Sysmon Event ID 3 (Network Connection) logs, which were collected by Wazuh.

# Impact Assessment

No exploitation occurred during this exercise.

The activity was limited to reconnaissance within an isolated and authorized virtual lab environment.

No changes were made to the target operating system.

---

# Root Cause

The activity was intentionally performed as part of a SOC Home Lab exercise to validate security monitoring and log collection capabilities.

---

# Response Actions

- Verified endpoint connectivity
- Executed controlled Nmap scan
- Collected Sysmon telemetry
- Reviewed Wazuh events
- Documented findings

---

# Lessons Learned

- Nmap reconnaissance generates useful network telemetry.
- Sysmon Event ID 3 provides valuable visibility into network connections.
- Wazuh successfully ingested Windows endpoint logs for investigation.
- Reconnaissance detection can be improved further using custom correlation rules.

---

# Conclusion

The simulated reconnaissance attack successfully demonstrated how endpoint telemetry generated by Sysmon can be collected and analyzed within Wazuh.

The lab validates visibility into network discovery activity and reinforces the importance of monitoring reconnaissance techniques during the early stages of the cyber attack lifecycle.
