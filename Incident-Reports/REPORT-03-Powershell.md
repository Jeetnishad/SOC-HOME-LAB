# Incident Report 02 – PowerShell Execution Detection

## Incident Summary

This incident documents the detection and investigation of PowerShell execution on a Windows 10 endpoint within the SOC Home Lab environment. The activity was intentionally generated to validate endpoint monitoring using Sysmon and Wazuh. The generated logs were analyzed to verify that PowerShell execution could be monitored and investigated through the Wazuh Dashboard.

# Executive Summary

PowerShell is one of the most commonly abused Windows administration tools. Threat actors frequently use it to execute commands, perform reconnaissance, download payloads, and establish persistence.

To validate endpoint visibility, multiple PowerShell commands were executed within the authorized SOC Home Lab. Sysmon recorded the process creation events and Wazuh collected the generated telemetry for investigation.

No malicious payloads were executed during this lab.

---

# Detection Timeline

| Phase | Description |
|--------|-------------|
| Step 1 | Opened PowerShell as Administrator |
| Step 2 | Executed Get-Process |
| Step 3 | Executed Get-ChildItem C:\Windows |
| Step 4 | Sysmon generated Process Creation events |
| Step 5 | Wazuh Agent forwarded the logs |
| Step 6 | Events investigated through the Wazuh Dashboard |

---

# Commands Executed

### Command 1

```powershell
Get-Process
```

Purpose:

Displays all currently running processes.

---

### Command 2

```powershell
Get-ChildItem C:\Windows
```

Purpose:

Lists the contents of the Windows directory and generates additional PowerShell activity for monitoring.

---

# Investigation

The investigation confirmed that PowerShell activity generated endpoint telemetry captured by Sysmon.

The collected information included:

- PowerShell process execution
- Process creation event
- Process path
- Command-line information
- Parent process
- User account
- Execution timestamp

The generated logs were successfully searchable within the Wazuh Dashboard.
