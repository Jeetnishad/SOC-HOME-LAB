# Executive Summary

A File Integrity Monitoring (FIM) alert was generated after changes were made to a monitored directory on the Windows endpoint. Wazuh successfully detected file creation, file modification, and file deletion activities within the configured monitoring path (`C:\FIM`).

The investigation confirmed that all activities were intentionally performed within the authorized SOC Home Lab environment for defensive security testing.

---

# Incident Description

A dedicated directory (`C:\FIM`) was configured for real-time monitoring using Wazuh Syscheck.

Three file system activities were performed:

- File Creation
- File Modification
- File Deletion

Each activity generated a corresponding Wazuh alert, demonstrating the effectiveness of File Integrity Monitoring.

# Recommendations

- Enable File Integrity Monitoring for sensitive directories.
- Monitor unauthorized file changes.
- Investigate unexpected checksum modifications.
- Correlate FIM alerts with Sysmon process events.
- Review file changes during incident response.
- Periodically validate monitoring configuration.
