# Incident Report – LAB 04 Reverse Shell Detection

## Incident Overview

This incident simulates a reverse shell attack using Netcat (Ncat) between a Windows 10 endpoint and a Kali Linux attacker machine within an isolated SOC home lab. The purpose of the exercise was to observe how endpoint telemetry generated by Sysmon is collected by Wazuh and investigated through the Threat Hunting module.

# Incident Description

A reverse shell connection was established from the Windows endpoint to the Kali Linux attacker system using Netcat. Once the connection was successful, an interactive Windows Command Prompt session became available on the attacker's machine.

Several Windows commands were executed remotely to verify the shell, including system identification and network information commands. Sysmon recorded the process creation events, and Wazuh collected the logs for centralized monitoring and investigation.

# Indicators Observed

- Execution of `ncat.exe`
- Command Prompt launched by an unexpected parent process
- Remote interactive shell session
- Outbound TCP connection from Windows to Kali Linux
- Process creation activity captured by Sysmon

---

# Analyst Investigation

The generated Sysmon events were successfully forwarded to the Wazuh Manager by the Wazuh Agent. During Threat Hunting, Wazuh identified abnormal command prompt execution and generated Rule ID **92052**. Reviewing the alert details confirmed that the command shell had been started by an unexpected process, indicating behavior commonly associated with reverse shell activity.

---

# Impact Assessment

The simulated reverse shell provided remote command execution capability on the Windows endpoint. Although executed in a controlled lab environment, similar behavior in a production network could indicate post-exploitation activity or unauthorized remote access requiring immediate investigation.

---

# Recommendations

- Monitor unusual process creation events.
- Investigate unexpected command shell executions.
- Restrict unauthorized remote administration tools.
- Continuously monitor Sysmon telemetry using Wazuh.
- Validate suspicious outbound network connections.

---

# Incident Status

**Status:** Closed

The reverse shell simulation was successfully detected and investigated within the SOC Home Lab. The collected telemetry demonstrated effective endpoint visibility and centralized log analysis using Sysmon and Wazuh.
